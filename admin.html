Backup e Segurança

Baixar backup completo

Gera um arquivo com todos os produtos, configurações do cardápio e histórico de pedidos. Guarde esse arquivo em local seguro — recomendado baixar periodicamente.

Restaurar backup

Restaura os produtos e a personalização a partir de um arquivo de backup baixado anteriormente. Isso substitui os dados atuais dessas duas áreas — o histórico de pedidos não é afetado. Use com cuidado.
